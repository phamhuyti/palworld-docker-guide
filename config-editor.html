Chỉnh cấu hình server trực quan

Mỗi tham số có control phù hợp và note giải thích. Ô viền hổ phách = đang khác mặc định game. Bấm một preset để áp nhanh, hoặc nhập file hiện tại của bạn để chỉnh tiếp — mọi thứ xử lý ngay trong trình duyệt, không có gì được gửi đi.

Nhập file cấu hình hiện tại

Mở Saved/Config/LinuxServer/PalWorldSettings.ini, copy toàn bộ và dán vào đây. Có thể dán cả 2 dòng hoặc chỉ dòng OptionSettings=(…).

Cấu hình xuất ra

Định dạng chuẩn 2 dòng — tô vàng là các giá trị khác mặc định. Dán đè toàn bộ file ini rồi restart container.
